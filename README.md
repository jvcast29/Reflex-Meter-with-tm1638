# Reflex-Meter-with-tm1638
Primer trabajo de digitales 2. 2026-1
First classwork 2026-1.

El  trabajo consiste en implementar el protocolo síncrono bidireccional del driver TM1638 sobre la plataforma ESP32 
utilizando MicroPython y desarrollar una lógica de control interactiva (Juego de Reacción Rápida) basada en 
temporizadores de hardware sin congelar el flujo general del programa.
